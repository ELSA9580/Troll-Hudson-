# TrollHUD (Fabric 1.21.11, Java 21)

Bauen ohne PC:
1. Neues GitHub-Repo anlegen, alle Dateien hochladen (inkl. Ordner .github).
2. Tab "Actions" -> Workflow "build" laufen lassen.
3. Fertige .jar steht unter dem Lauf bei "Artifacts" (trollhud).
4. Die .jar (nicht die -sources.jar) in den mods-Ordner legen, dazu Fabric API.

Bauen am PC: `gradle build` (Gradle 9.2.1, JDK 21) -> build/libs/

Taste fuer das Menue: Optionen > Steuerung > Tastenbelegung > TrollHUD (Standard: Rechts-Shift).
Auf dem Tablet in Zalith einen Touch-Button mit dieser Taste belegen.
